## 🌐 Interfaz Web Interactiva (`index.html`)

El repositorio incluye una aplicación web interactiva en **[`index.html`](file:///index.html)** con:
* 🔍 Buscador en tiempo real de herramientas y comandos.
* 🏷️ Filtros dinámicos por categorías (Seguridad, UI/UX, Full-Stack, Arquitectura, etc.).
* 📋 Botones de un solo clic para copiar comandos de instalación (`npx skills add`, `npm i`, `git clone`).
