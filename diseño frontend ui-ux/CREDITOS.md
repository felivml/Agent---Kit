### 💡 Descripción y Contribución de `nextlevelbuilder`
Proporciona un motor de búsqueda BM25 local y un generador de sistemas de diseño completo para que los agentes de IA no produzcan interfaces genéricas o "slop de IA", sino diseños específicos con reglas de negocio:
1. **192 reglas de razonamiento** clasificadas por industria (SaaS, FinTech, E-commerce, Salud, etc.).
2. **79 estilos de UI documentados** (Minimalismo, Bento Grid, Neumorphism, Glassmorphism, Brutalism).
3. **192 paletas de color armoniosas** con tokens CSS (`--color-primary`, `--color-background`, etc.) y contraste WCAG 4.5:1.
4. **74 combinaciones tipográficas** con Google Fonts listos para importar.
5. **Checklists anti-patrones** para forzar accesibilidad, cursores, micro-interacciones y buenas prácticas de UI/UX.
